## 🚀 Running & Previewing Locally

Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari).

Or run a local development server using Python:
```bash
# In the project directory:
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

## 🌐 Deploying to GitHub Pages / Vercel

### GitHub Pages:
1. Push this folder to a GitHub repository.
2. Go to repository **Settings** -> **Pages**.
3. Set Source to **Deploy from a branch** (`main` / root).
4. Save — your website is live in ~1 minute.

### Vercel / Netlify:
- Drag and drop the `cloud9-web-solutions` directory directly onto [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant global edge deployment.
